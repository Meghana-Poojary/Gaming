## 🎮 Mini Games Included

### 🟡 Simon Game
A memory-based game where users must repeat an ever-growing sequence of lights and sounds. Great for testing and improving short-term memory and attention span.

### 🎲 Dicee Game
A fun and simple dice-rolling game where two virtual dice are rolled, and the player with the higher roll wins. A classic luck-based game useful for basic randomization logic.

### 🥁 Drum Kit Game
An interactive virtual drum kit where users can play different drum sounds using keyboard keys or mouse clicks. Enhances auditory coordination and rhythm practice.
